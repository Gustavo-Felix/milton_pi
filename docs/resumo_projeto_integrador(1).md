# Projeto Integrador — Resumo das Etapas Concluídas e Alinhamento Inicial

## Infraestrutura e Ferramentas de Trabalho

- **Versionamento e CI/CD:** Criação do repositório oficial no GitHub para controle de versão do código-fonte e futuras integrações contínuas.
- **Gestão Ágil:** Organização do quadro no Trello (Kanban) para mapeamento do backlog, distribuição de tarefas e acompanhamento de sprints.
- **Comunicação:** Configuração de um servidor dedicado no Discord como hub central para reuniões e comunicação assíncrona.

## Engenharia de Dados e Pesquisa Inicial

- **Levantamento de Fontes:** Identificação, seleção e validação de fontes de dados alternativas e públicas (APIs abertas e datasets públicos) para fundamentar a arquitetura do sistema.

## Metodologia e Rituais Ágeis

- **Alinhamentos Semanais:** Definição de reuniões fixas (Dailys / Sprint Planning) todas as terças-feiras, às 15h00, para acompanhamento de metas e validação técnica.
